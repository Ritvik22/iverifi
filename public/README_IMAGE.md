# Penguin Image Setup

To complete the landing page design, please add your penguin image file:

1. Save your penguin image as `penguin.png` in the `public/` directory
2. The image will automatically be displayed in the hero section
3. If the image is not found, a fallback emoji (🛡️) will be displayed instead

Supported formats: PNG, JPG, SVG
Recommended size: 600x600px or larger for best quality
